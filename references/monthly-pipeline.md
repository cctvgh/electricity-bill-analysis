
# 月度电费数据上游处理流水线（8步）

> 2026-09-25 对照实际脚本逐条核实整理。原操作说明：`202212起每月南网供电电费清单汇总\日常操作每月南电清单核查步骤说明电费分析202507.txt`。
> **原则：当说明文字与脚本代码不一致时，以代码实际行为为准**（已知差异在各步骤中标注）。

## 流程总览

```
收单清洗(41) → 全量合并(42) → 打标(202512) → 去长(44，报表图专用)
  → 两月差值分析(45) → 防溺水·去长版(46，对外简报) → 防溺水·未去长版(47，内部核对)
  → 大于50元防溺水异常筛选
```

## 各步骤详解

### 第1步 收单清洗 — 供电清单改名及数据清洗41.py

- **输入**：供电部门提交的《电信YYMM(YYMMDD)》供电清单（来源标识 zjyeyc，为提交渠道/账号，本机无同名文件夹）。注意区分：**不是**《电量电费表（含线路）》——后者2026年起存`202601起新格式\`，本流程不用。
- **前置检查**：清洗文件夹内必须只有1个Excel（否则脚本报"Excel文件数量不为1"退出）；放入新文件前先移走上月残留。
- **实际行为**：
  - 从原文件名括号中提取年月，重命名为`电信YYMM月.xlsx`（年份后2位+月份2位+"月"）；
  - 删除无用户编号的行；用户编号按字符串处理；
  - **去重汇总针对所有重复用户编号**（说明写"总电量为0的行"不准确）：相同用户编号保留抄表日期最新一行，总电量/总电费按组求和。
- **输出**：`电信YYMM月.xlsx`，需移入`历史数据月份电量\`。

### 第2步 全量合并 — 2025月度电费合并42.py

- **输入**：`历史数据月份电量\`下所有`电信*.xlsx`（匹配规则：以"电信"开头、`.xlsx`结尾，文件名带不带"月"字均兼容）。
- **执行前检查**：删除工作表空行；确认无未保存修改、无`~$`开头Excel临时文件。
- **行为**：读取所有文件所有工作表，规范化列名后按12个关键字段筛选：用户编号、用户名称、电费年月、出厂编号、用电地址、供电单位、用电类别、电价、平均电价、总电量、应收电费；缺关键字段的表跳过。
- **输出**：`合并后的电费数据.xlsx`（存于`历史数据月份电量\`）。

### 第3步 打标 — 电费数据分析与打标脚本202512.py

- **位置**：`打标资料汇总\`（目录内另有202605系列更新版，操作说明指定以202512为准）。
- **执行前**：先把最新`合并后的电费数据.xlsx`复制到`打标资料汇总\`。
- **行为**：加载目录下所有以"打标"结尾的xlsx（自动跳过`~$`临时文件），构建 用户编号→[电表用途] 映射；为`合并后的电费数据.xlsx`回填电表用途1、电表用途2、电表用途汇总三列（无匹配填"没有找到"），覆盖保存。
- **后处理（勿漏）**：删除"电表用途1、电表用途2"两列，将"电表用途汇总"列名改为"电表用途"——后续44/45/46/47均依赖"电表用途"列过滤。
- **⚠️ 编号位数陷阱（2026-09实测）**：`防溺水电表唯一打标.xlsx` 等台账为15位编号（"308"开头），月度清单为16位（"0308"开头），202512.py 直接匹配会漏掉防溺水电表且无报错；自写打标/分析代码必须先做编号归一化（去前导零），打标后核对防溺水匹配数应约重点监控电表。

### 第4步 去长（可选，报表图专用）— 2025月度电费地址去长豆包44.py

- **输入**：主工作目录下`合并后的电费数据_已打标.xlsx`。
- **实际行为**（说明写"只保留最后7个文字"不准确）：
  - 用电地址去除：（防溺水监控）、城北街道办、XX运营商股份有限公司、XX分公司、广东省、广东、XX区、XX市、镇（比说明多"广东省、广东"两项），保留**末30字节**（约10个汉字），不足30字节前置'A'；
  - 用户编号保留末4位数字，前置'A'；电表用途去除"（重复用户）"；用户名称按前缀缩写（运营商A系→ZF、运营商B系→LF、合作单位C→LFGD）。
- **输出**：`合并后的电费数据_已打标已去长.xlsx`。

### 第5步 两月差值分析 — 2025两月电费增加差值分析0705豆包45.py

- **输入**：主工作目录下`合并后的电费数据.xlsx`。
- **每月必改**：`filter_and_analyze_data(target_months=[YYYYMM, YYYYMM])`，**先替换最近月份、后替换较远月份**；基准期为目标月前推3个月（自动计算），异常阈值50%。
- **输出**：Excel分析报告+图表+控制台汇总（供报告生成环节使用）。

### 第6/7步 防溺水分析 — 46（去长版）/ 47（未去长版）

| | 46号 | 47号 |
|---|---|---|
| 输入 | `合并后的电费数据_已打标已去长.xlsx` | `合并后的电费数据_已打标.xlsx` |
| 用途 | 对外简报/报表图 | 内部核对（完整用电地址） |
| 输出 | `YYYYMM防溺水监控电表电费分析.xlsx/.docx` → 根目录 | 同左，新版文件名带"_未去长"后缀 |

- 筛选电表用途='防溺水监控'，两月对比，输出变动超50%电表、本月大于100元电表、统计描述表与图表。
- **推荐使用月份变量版**（2026-09-25新增，原脚本保留未动）：
  - `统计分析异常差值上本月防溺水46_月份变量版.py`
  - `统计分析异常差值上本月防溺水未去长47_月份变量版.py`
  - 每月仅需修改顶部两行：`CURRENT_MONTH`（本月/分析期）、`PREV_MONTH`（上月/对比期），输出文件名、Excel工作表名、Word标题/表头/正文月份全部自动同步。
- **新版相对旧版的修复**：
  1. 修复旧46脚本Word正文硬编码"2025年4月"笔误（实际当月为9月）；
  2. 47输出文件名加"_未去长"后缀——旧版46/47同月输出完全同名文件，后跑的覆盖先跑的；
  3. 空数据保护：忘改月份或本月数据未入库时提示"数据为空"安全退出，不生成文件、不覆盖旧档。
- 建议顺序：先跑47核对地址，再跑46出对外简报（两者保持相同月份配置）。

### 第8步 大于50元防溺水异常筛选

异常用户明细子表中，筛选当前月应收电费大于50元且电表用途为"防溺水监控"的用户（历史积累：`202303-202606年应收电费大于50元且电表用途为防溺水监控电表清单.csv`）。另有重点监控台账只防溺水电表唯一打标台账`防溺水电表唯一打标.xlsx`，可用VLOOKUP导出地址等信息。

## 常见陷阱

| 陷阱 | 现象 | 处置 |
|------|------|------|
| 清洗文件夹多Excel残留 | 41脚本报"Excel文件数量不为1" | 放新清单前先移走旧文件 |
| 46/47旧版同名覆盖 | 同月两脚本输出同名文件互相覆盖 | 用新版（47带"_未去长"后缀） |
| 忘改月份 | 旧版拿旧月份数据跑并覆盖结果 | 新版空数据保护自动退出 |
| 月文件命名不统一 | `电信202510.xlsx`缺"月"字、`电信2606月.xlsx`缺"20"前缀 | 42能兼容，建议统一`电信YYMM月.xlsx` |
| Excel临时文件 | `~$`开头文件混入 | 关闭Excel再跑脚本；打标脚本已自动跳过 |
| 历史缺月 | 2023年4月（2304）数据缺失 | 同比分析时注意 |
| 打标后未删列改名 | 44/46/47按"电表用途"过滤失败 | 第3步后处理勿漏 |
| 打标编号前导零差异 | 台账15位"308"开头 vs 清单16位"0308"开头，直接匹配防溺水得0只且**无报错** | 匹配前归一化去前导零（见SKILL.md关键数据陷阱）；打标后核对防溺水应约重点监控电表 |
| 电费年月浮点格式 | 合并数据年月为 `202607.0`，字符串比较 `'202607'` 得0行且无报错 | 筛选前归一化为6位字符串 |
| 合并/打标文件为旧档 | 最新月份在合并数据中0行（如202607/202608缺失） | 先重跑42合并+打标，或直接从月度清单现算 |

## 每月作业清单

1. 收到供电清单 → 清空清洗文件夹旧Excel → 放入新清单
2. 跑41 → 输出`电信YYMM月.xlsx`移入`历史数据月份电量\`
3. 检查空行/临时文件 → 跑42 → 得`合并后的电费数据.xlsx`
4. 复制到`打标资料汇总\` → 跑202512打标 → 删"电表用途1/2"两列、"电表用途汇总"改名"电表用途"
5. （报表图需要时）跑44去长
6. 跑45（改`target_months`，先近后远）
7. 跑47新版（改`CURRENT_MONTH/PREV_MONTH`）核对完整地址
8. 跑46新版出对外简报
9. 异常用户明细中筛选大于50元防溺水用户
