
# 月度电费分析报告结构参考

## 报告板块与数据来源映射

| 板块 | 数据来源 | 必要内容 |
|------|---------|---------|
| 总体电费情况 | analysis_result.json → overall, fee_distribution | 四宫格统计卡片、环比增减、电费分档分布表 |
| 按用途分类分析 | analysis_result.json → usage_summary, meter_usage | 分类汇总表、各类用途文字分析 |
| 异常用户分析 | analysis_result.json → abnormal, abnormal_by_purpose | 分类统计表、严重异常TOP10表、重点用户文字分析 |
| 高耗能用户分析 | analysis_result.json → top_consumers | TOP10表格、文字分析 |
| 新增及流失用户 | analysis_result.json → new_users, lost_users | 新增表、流失表、文字分析 |
| 工作建议 | 基于异常分析综合判断 | 3~5条针对性建议 |
| 历史对比（如有） | analysis_result.json → comparison | 环比/同比变化对比 |

## 各板块写作要点

### 总体电费情况
- 开头用四宫格展示：当月总电费、上月总电费、环比增减额、环比增长率
- 段落描述总体趋势（平稳/增长/下降）
- 说明"长尾"特征：低电费用户占比、高耗能用户占比及贡献率
- 电费分档表：区间、户数、占比、主要用途

### 按用途分类分析
- 汇总表：用途、户数、当月电费、上月电费、环比增减、增长率、电费占比
- 分用途文字分析，重点说明：
  - 综合机房：电费占比最大，关注空调能耗和设备负载
  - 接入网机房：中等耗能，关注扩容变化
  - 防溺水监控：户数多单户低，关注季节性波动和异常增长
  - 治安视频监控：户数少电费低，波动小
  - 用途待核实：占比偏高是管理短板，需推进标注

### 异常用户分析
- 异常用户分类统计表（按用途）
- 严重异常TOP10表（按电费差值排序，标注用途和基准增长率）
- 重点用户文字分析，选取3~6个典型用户：
  - 电费差值最大的防溺水监控用户
  - 基准增长率最高的用户
  - 用途待核实中差值最大的用户
  - 接入网机房异常用户（如有）
  - 地址相近的多个异常点位（可能同源）

### 高耗能用户分析
- TOP10表格（按当月电费排序）
- 文字分析：关注环比增减最大的用户、电费突降的用户

### 新增及流失用户
- 新增用户表：地址、当月电费、备注（高耗能/低耗能/零电费）
- 流失用户表：地址、上月电费、用途
- 文字分析：新增用户区域分布、高耗能新增需关注

### 工作建议（5条标准建议+针对本月特殊情况的补充）

1. **核查严重异常用户**：针对基准增长率≥50%的用户，2周内现场核查
2. **推进电表用途标注**：关注待核实用户占比和增量贡献
3. **加强防溺水监控管控**：汛期/高温季节重点关注
4. **持续关注高耗能机房**：永兴区等大机房运行负载和空调节能
5. **常态化电费异常监测**：三级预警机制，标注率考核

## 历史对比写作要点

当有历史数据时，在报告"总体电费情况"板块增加：
- 连续N个月电费趋势
- 异常用户数量环比变化
- 各用途电费环比变化趋势
- 新增/流失用户数量趋势
