# 企业电费异常分析报告生成器

> 管上千只电表的你，每月电费对账还要肉眼找异常？把清单丢给它：总体电费、按用途分类、异常用户、高耗能用户、新增流失用户，六板块 HTML 报告一键生成，逐月积累支持环比/同比。

## 为什么需要它

多电表企业（物业、园区、连锁门店、基站/机房集群）的电费管理有三个老大难：

1. **清单太厚**：每月供电电费清单几十列、上千行，异常靠肉眼和筛选，漏一只就是一笔糊涂账
2. **报告重复**：每月的《电费异常分析报告》结构雷同，数据变了但写法不变，纯体力活
3. **降本无据**：市场化入市、两部制、峰谷电价、转供电追退、需求响应——政策都懂，但自家数据能不能享受、能省多少，没人算得清

本工具以南方电网供电电费清单为原生适配对象（其他地区清单按字段映射即可），把上述三件事全部自动化。

## 功能亮点

| 板块 | 输出 |
|------|------|
| 总体电费情况 | 总金额、电量、均价、环比/同比 |
| 按电表用途分类 | 基站 / 机房 / 办公 / 监控等分组统计 |
| 异常用户分析 | 电费突增/突降户定位，附变化幅度 |
| 高耗能用户 | TopN 排行与占比 |
| 新增/流失用户 | 两月对比自动识别 |
| 工作建议 | 基于异常数据生成处置建议 |

**进阶能力：**

- **历史数据积累**：每月分析结果落盘 JSON，随时间推移自动支持同比/环比趋势
- **五项降本政策可行性评估**：市场化入市 / 两部制 / 峰谷电价 / 转供电追退 / 需求响应，用你的真实清单数据测算每项能省多少
- **防溺水监控电表专项简报**：面向安全生产场景的重点电表监控输出

## 快速开始

1. 准备每月供电电费清单 Excel（南网清单原生支持）
2. 修改 `scripts/analyze_electricity.py` 中的数据目录指向你的清单目录
3. `python scripts/analyze_electricity.py 202608` → 生成当月 HTML 报告

## 数据陷阱（作者踩过的坑，都在参考文档里）

用户编号前导零差异、电费年月浮点化、台账与清单编号位数不一致——这些会导致匹配**静默失败为 0 行且不报错**。处理方法与验证步骤已写入 `references/`。

## 适用人群

- 物业公司 / 园区后勤电费管理员
- 多电表企业（连锁、楼宇、工厂）财务与能源岗
- 通信运营商基站/机房电费管理员
- 南方电网区域（粤桂滇黔琼）的用电大户

## 作为 TeleAgent 技能使用

本工具同时发布为「星辰超级智能体（TeleAgent）」技能 **`electricity-bill-analysis`（企业电费异常分析报告）**，技能市场安装后直接说"电费分析""生成电费报告""防溺水简报"即可。

配套技能：[`nanwang-daily-electricity-fetch`](https://github.com/cctvgh/nanwang-daily-electricity-fetch)（南网在线日电量监控与提醒）补齐日级数据时效。
